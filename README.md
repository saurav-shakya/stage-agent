# One User, One Agent

An agent per viewer that, on every app open, picks one measurable goal from cited evidence, decides what to
change (a home page, at most one message, or nothing), checks that decision independently before publishing, and
later judges the goal and the agent's impact against the randomized holdout.

Python 3.11+, standard library only. No API key needed: the replay uses a deterministic mock model provider that
also reproduces `replay/model_faults.jsonl` and the outages in `replay/control_events.jsonl`.

## Setup

```bash
git clone <this repo> && cd stage-agent
# put the data pack here (it is git-ignored: it is treated as personal data)
unzip one_user_one_agent_data_pack.zip -d data_pack
```

The pack is found automatically at `data_pack/one_user_one_agent_pack/` (what the unzip above produces) or directly
in `data_pack/`. To use a pack elsewhere, pass `--pack <dir>` or set `OUA_PACK=<dir>`; either may point at the pack
itself or at the folder the zip was extracted into. An explicit path that does not hold the pack is an error: it
never falls back to the default location. A missing pack stops `run` and fails the tests with the paths searched.

## One command: replay the trigger script

```bash
python -m src.cli run --out sample_run
```

This (about 10-20 s on a laptop):

1. replays `triggers.jsonl`, `live_events.jsonl` and `control_events.jsonl` in delivery order through the agents,
2. writes `decisions.jsonl` and `actions.jsonl`,
3. runs the pack's simulator on the actions (`--seed oua-practice` by default; evaluators can pass their own),
4. judges every goal from the simulator's outcome events and feeds the result back into viewer state,
5. writes the impact, latency and final reports.

Useful options: `--seed`, `--workers 4`, `--model-timeout-ms 2500`, `--max-model-calls 8`, `--max-tool-calls 20`,
`--no-messages` (home page only).

## Tests

```bash
python -m unittest discover -s tests -t . -v
```

37 tests. 23 agent tests run on a small synthetic pack whose configs are copied from the real pack, which is
located as in Setup. If the pack cannot be found they fail with an error; they are never silently skipped. They cover duplicate, same-session, offline-buffered and wrong-clock triggers; a three-way dialect
conflict, duplicate profile rows and a purchase that contradicts the snapshot; model timeout, malformed output,
unsupported confident claim, model outage with circuit breaker, a slow model that trips the circuit
breaker after repeated timeouts, and data-store outage; a corrected goal rule that
re-points only open goals of that goal id; a corrected rule the agent cannot read (unknown wording or an event
that does not exist) judged inconclusive instead of success, with no new viewer committed to it; a changed number
of days honoured; every catalogue goal measurable except G10 and G11; every evidence reference carrying its source and freshness; holdout safety, messaging rules, catalogue instruction text, and a
title withdrawn mid-day. 6 more tests cover finding the pack in both layouts and failing on a missing or wrong path, and 5 cover
the model client's circuit breaker and the degraded-dependency profile, and 3 cover parsing success-rule
conditions (no pack needed).

## Inspect one viewer

```bash
python -m src.cli viewer U-02825 --out sample_run
```

```bash
python -m src.cli viewer U-01991 --out sample_run --at 2026-10-01T12:00:00Z
```

Prints what the agent knew (every fact with source, reference, age and conflicts), what it decided and why, what
it published, and the journal (replans, cancellations, rule corrections, outcome, learning) up to `--at`. The same
information is in `sample_run/viewer_state/<viewer>.json`. `state.sqlite` is regenerated by `run`, so run it first.

## Output (`sample_run/`)

| File | What it is |
|---|---|
| `decisions.jsonl` | One record per trigger: goal, action or no-action reason, dialect and its conflicts, content, confidence with reasons, evidence (with freshness), assumptions, check results, timings |
| `actions.jsonl` | Exactly what the platform receives (input to the simulator) |
| `outcomes.jsonl` | Every goal judged succeeded / failed / inconclusive, with evidence, exposure and attribution, and the learning recorded |
| `viewer_state/` | Per-viewer state: latest facts with provenance, goals, decisions, actions, outcomes, journal |
| `latency_report.json` | Publish delay overall, during each outage window, at the evening peak and in the busiest 10 minutes |
| `impact_report.md` | Agent vs randomized holdout (ITT) with confidence intervals; why the served-vs-unserved comparison misleads; the pilot re-analysis |
| `final_report.md` | Factual record of the run: decisions by reason, verifier rejections, outcomes, how each surprise was handled |
| `sim/simulator_report.json` | The simulator's own counters, including policy problems (0 in this run) |

## Code map

| Module | Role |
|---|---|
| `src/pack.py` | Loads the pack; per-viewer event history deduplicated by `event_id`, ordered by `received_at` |
| `src/facts.py` | Fact resolver: per-fact precedence and freshness, conflicts kept visible |
| `src/goals.py` | Goal eligibility with evidence, versioned success rules, judging |
| `src/content.py` | Home page builder (dialect, availability, one title per content) |
| `src/llm.py` | Model provider interface, mock provider, call wrapper (budget, timeout, strict parsing, circuit breaker), dependency health, data store |
| `src/verifier.py` | Independent checks before publishing |
| `src/agent.py` | `Runtime` (routing, control events) and `ViewerAgent` (decide, replan) |
| `src/store.py` | SQLite state: facts, decisions, actions, goals, outcomes, journal |
| `src/replay.py` | Replay harness with a worker pool, so bursts show up as queueing delay |
| `src/judge.py`, `src/impact.py`, `src/reports.py` | Closing the loop and measurement |
